# Проект: точки Лагранжа

Проект посвящён точкам Лагранжа в ограниченной круговой задаче трёх тел.
План работы состоит из двух частей:

- теоретическая часть в `TeX` с последующей компиляцией в `PDF`;
- вычислительная часть с моделированием траекторий в окрестности точек Лагранжа.

## Структура проекта

```text
mechanics/
├─ README.md
├─ .gitignore
├─ docs/
│  ├─ tex/
│  │  ├─ main.tex
│  │  ├─ preamble.tex
│  │  ├─ titlepage.tex
│  │  └─ sections/
│  ├─ pdf/
│  └─ sources/
│     ├─ books/
│     └─ articles/
├─ code/
│  ├─ src/
│  └─ notebooks/
├─ results/
│  ├─ figures/
│  └─ animations/
├─ data/
└─ scripts/
```

## Что где хранить

- `docs/tex/` — исходники отчёта в `TeX`
- `docs/tex/preamble.tex` — общая преамбула документа
- `docs/tex/titlepage.tex` — отдельный титульный лист
- `docs/pdf/` — скомпилированный итоговый `PDF`
- `docs/sources/books/` — книги и основной теоретический материал
- `docs/sources/articles/` — статьи, конспекты и дополнительные источники
- `code/src/` — код вычислений
- `code/notebooks/` — исследовательские ноутбуки
- `results/figures/` — статические картинки траекторий
- `results/animations/` — анимации движения
- `data/` — параметры систем и сохранённые численные данные
- `scripts/` — вспомогательные скрипты
